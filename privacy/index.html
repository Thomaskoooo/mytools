Privacy Policy

Short version: almost every tool runs entirely in your browser. Your input is never sent anywhere for those tools. Two tools need a server request to work at all — DNS Lookup and the HTTP Headers Checker — and both are clearly labeled.

Client-side tools ("runs locally in your browser")

Tools marked with the green runs locally in your browser badge — including the IP Calculator, VLSM Calculator, IP Address Information, JSON Formatter, Base64, JWT Decoder, UUID Generator, Hash Generator, Text Counter, Case Converter, Lorem Ipsum, Password Generator, QR Code Generator, Timestamp Converter, Number Base Converter, URL Encoder, HTML Entity Encoder, HTTP Status Lookup and Regex Tester — process everything using JavaScript running on your own device. Nothing you type into these tools is transmitted to our servers, logged, or stored anywhere.

Server-side tools ("requires server request")

Tools marked with the amber requires server request badge — DNS Lookup and the HTTP Headers Checker — must contact a server, because browsers cannot perform raw DNS queries or read cross-origin response headers directly. For these two tools:

  • The domain or URL you submit is sent to our serverless function, which performs the lookup and returns the result to you.
  • We do not write the domains or URLs you check to any database or persistent log. Cloudflare's standard, short-lived infrastructure request logs (used for abuse prevention and debugging) may briefly include the request, consistent with Cloudflare's own logging practices.
  • The HTTP Headers Checker refuses to contact local or private network addresses (localhost, private IP ranges, link-local addresses, etc.) as a security measure — see the tool page for details.

No accounts, no analytics by default

MyTools has no user accounts, no login, and does not use third-party analytics or advertising trackers. If analytics are ever added, it will be a privacy-respecting, cookie-free option and this page will be updated first.

Cookies & local storage

We use your browser's localStorage only to remember your dark/light mode preference. This never leaves your device and is never read by our servers.

Third-party services

DNS Lookup and the HTTP Headers Checker make outbound requests to public DNS resolvers and the URLs you provide, respectively, in order to return a result. No other third-party service receives your data.

Changes to this policy

If this policy changes in a way that affects how your data is handled, this page will be updated and the date below will reflect it.
