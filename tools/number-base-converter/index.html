Number Base Converter

Type a number into any field and watch it convert live to binary, decimal, hexadecimal and octal.

runs locally in your browser

About this tool

This converter lets you type a value into any of the four fields — binary, decimal, hexadecimal or octal — and instantly fills in the other three. It uses JavaScript's BigInt internally, so it stays accurate even for numbers far larger than a normal 32-bit or 64-bit integer can hold. Invalid characters for the selected base are flagged immediately so you always know the value you're seeing is a correct conversion.
