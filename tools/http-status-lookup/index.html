About this tool

HTTP status codes are three-digit numbers a server returns with every response to tell the client what happened to its request. The first digit defines the category — 1xx informational, 2xx success, 3xx redirection, 4xx client error and 5xx server error — while the rest identifies the specific outcome. Understanding these codes is essential for debugging APIs, configuring redirects and diagnosing why a request failed.
