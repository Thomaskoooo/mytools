UUID Generator

Generate one or many random RFC 4122 version 4 UUIDs, with uppercase and hyphenation options.

runs locally in your browser

About this tool

This generator creates random version 4 UUIDs (universally unique identifiers) as defined by RFC 4122, using your browser's cryptographically secure random number generator. It uses crypto.randomUUID() when available, with a manual fallback built from crypto.getRandomValues that sets the correct version and variant bits. Generate up to 100 at once, toggle uppercase or remove hyphens, and copy any single value or the whole batch.
