About this tool

      
A JWT (JSON Web Token) has three Base64URL-encoded parts separated by dots: a header, a payload and a signature. This tool decodes the header and payload entirely in your browser — the token never leaves your device. It does not and cannot verify the signature, since that requires the issuer's secret or public key, which this tool never has access to.
