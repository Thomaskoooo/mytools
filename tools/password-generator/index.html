Password Generator

Generate strong random passwords with adjustable length and character sets.

runs locally in your browser

About this tool

Passwords are generated using crypto.getRandomValues(), the browser's cryptographically secure random number source, with rejection sampling to avoid modulo bias. The password is never transmitted anywhere — it's generated and displayed entirely on your device. The entropy estimate (in bits) reflects how many character-set combinations an attacker would need to brute-force; aim for at least 60 bits for most accounts, more for anything sensitive.
