About this tool

      
URL (percent) encoding replaces characters that aren't allowed in a URL — spaces, ampersands, slashes within a query value and more — with a percent sign followed by their hex byte value. This tool uses the browser's built-in encodeURIComponent and decodeURIComponent functions, so results match exactly what JavaScript and most web frameworks produce. Malformed percent sequences are caught and reported clearly instead of crashing.
