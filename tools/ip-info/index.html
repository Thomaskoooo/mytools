IP Address Information

Enter an IPv4 address to see its binary and hex form, class, and private/public status.

runs locally in your browser

About this tool

This tool decomposes an IPv4 address into its binary and hexadecimal representations and checks it against the well-known reserved ranges: private (RFC 1918), loopback (127.0.0.0/8), link-local (169.254.0.0/16) and multicast (224.0.0.0/4). It also reports the historical classful network class (A/B/C/D/E), which is largely superseded by CIDR today but still useful for learning.
