About this tool

This tester runs your pattern through JavaScript's native RegExp engine as you type, so what you see matches exactly what String.match or .test() would return in real code. Matches are highlighted directly in your test string, and each match's full text, numbered capture groups and named groups (if any) are listed below with a one-click copy button. A syntax error in your pattern is shown immediately with the real JavaScript error message instead of silently failing.
